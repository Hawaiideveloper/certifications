Question 1 of 10
A security analyst discovers that an attacker has gained access to the network by sending a specially crafted email with a malicious PDF attachment to the CFO. The PDF exploited a zero-day vulnerability in the PDF reader. Which type of attack is this?
  • A. Watering hole attack
  • B. Spear phishing
  • C. Vishing
  • D. Pharming
Answer: B

Spear phishing is a targeted phishing attack directed at a specific individual or organization. Unlike generic phishing, spear phishing uses personalized content (in this case, targeting the CFO specifically) and often includes weaponized attachments. The use of a zero-day exploit makes this a sophisticated attack. A watering hole compromises websites the target visits; vishing uses voice calls; pharming redirects DNS traffic to malicious sites.

Question 2 of 10
An organization wants to implement a security model where no user or device is automatically trusted, regardless of whether they are inside or outside the network perimeter. Which security framework best describes this approach?
  • A. Defense in depth
  • B. Least privilege
  • C. Zero trust
  • D. Role-based access control
Answer: C

Zero trust is a security framework based on the principle of "never trust, always verify." It requires continuous verification of every user, device, and network flow regardless of location. Key components include micro-segmentation, least-privilege access, multi-factor authentication, and continuous monitoring. Unlike traditional perimeter-based security, zero trust assumes the network is already compromised and verifies every access request.

Question 3 of 10
A web application developer discovers that user input in a search field is being directly inserted into a SQL query without sanitization. An attacker enters: ' OR '1'='1' -- into the search field. What type of vulnerability is being exploited?
  • A. Cross-site scripting (XSS)
  • B. SQL injection
  • C. Cross-site request forgery (CSRF)
  • D. Buffer overflow
Answer: B

SQL injection occurs when an attacker inserts malicious SQL code into input fields that are incorporated into database queries without proper sanitization or parameterization. The payload ' OR '1'='1' -- modifies the WHERE clause to always evaluate as true, potentially returning all records. The -- comments out the rest of the query. Prevention includes using parameterized queries (prepared statements), input validation, and stored procedures.

Question 4 of 10
During a security audit, an analyst discovers that several former employees still have active VPN accounts. Which security control failure does this represent?
  • A. Inadequate authentication mechanisms
  • B. Missing encryption on the VPN tunnel
  • C. Failure in the offboarding/deprovisioning process
  • D. Lack of network segmentation
Answer: C

This represents a failure in the identity lifecycle management process, specifically the offboarding/deprovisioning phase. When employees leave an organization, their accounts should be immediately disabled or deleted as part of a formal offboarding procedure. Active accounts for former employees create a significant security risk as they could be used for unauthorized access. This is addressed through proper HR-IT integration, automated deprovisioning workflows, and regular access reviews.

Question 5 of 10
A company needs to encrypt data at rest on its file servers. The data must be accessible by multiple authorized users who each have their own encryption keys. Which encryption approach is most appropriate?
  • A. Full disk encryption with a single shared key
  • B. Asymmetric encryption where data is encrypted with a symmetric key, and the symmetric key is encrypted with each user's public key
  • C. Hashing the data with SHA-256
  • D. Using a single symmetric key stored in a text file on the server
Answer: B

This is a hybrid encryption approach (also called envelope encryption). The data is encrypted with a fast symmetric key (e.g., AES), and then that symmetric key is encrypted separately with each authorized user's public key. Each user can decrypt the symmetric key with their private key and then decrypt the data. This is efficient because the large data is encrypted only once, and key distribution is managed through PKI. Hashing is one-way and does not allow decryption.

Question 6 of 10
A SIEM alert shows multiple failed login attempts from a single IP address targeting different user accounts over a short period. What type of attack is most likely occurring?
  • A. Brute force attack against a single account
  • B. Password spraying attack
  • C. Credential stuffing attack
  • D. Rainbow table attack
Answer: B

Password spraying targets multiple accounts with a few commonly used passwords, attempting to avoid account lockout thresholds. Unlike brute force (which targets one account with many passwords) or credential stuffing (which uses stolen username/password pairs from breaches), password spraying distributes attempts across many accounts. Defenses include implementing MFA, monitoring for distributed login failures, using account lockout policies, and enforcing strong password requirements.

Question 7 of 10
An organization is implementing a disaster recovery plan. They determine that the maximum amount of data loss they can tolerate is 4 hours. Which metric defines this requirement?
  • A. Recovery Time Objective (RTO)
  • B. Recovery Point Objective (RPO)
  • C. Mean Time to Repair (MTTR)
  • D. Maximum Tolerable Downtime (MTD)
Answer: B

Recovery Point Objective (RPO) defines the maximum acceptable amount of data loss measured in time. An RPO of 4 hours means backups must be performed at least every 4 hours. RTO is the maximum acceptable time to restore service after a disruption. MTTR is the average time to repair a failed component. MTD is the maximum total time a business function can be unavailable. RPO directly drives backup frequency and replication strategy decisions.

Question 8 of 10
A security team needs to verify the integrity of a critical system file to ensure it has not been modified by malware. Which technique should they use?
  • A. Encrypt the file with AES-256
  • B. Digitally sign the file with the server's private key
  • C. Compare the current file hash against a known-good baseline hash
  • D. Compress the file and check the archive size
Answer: C

File integrity monitoring (FIM) uses cryptographic hashing (such as SHA-256) to create a unique fingerprint of a file. By comparing the current hash against a known-good baseline hash, any modification to the file will be detected because even a single bit change produces a completely different hash value. This is a core integrity verification technique. Tools like AIDE, Tripwire, and OSSEC automate this process across filesystems.

Question 9 of 10
An organization's security policy requires that a single administrator cannot both create a user account and assign elevated privileges to that account. Which security principle does this policy enforce?
  • A. Least privilege
  • B. Need to know
  • C. Separation of duties
  • D. Mandatory access control
Answer: C

Separation of duties (SoD) ensures that no single individual has complete control over a critical process. By requiring different administrators to create accounts and assign privileges, the organization prevents a single compromised or malicious administrator from creating unauthorized privileged accounts. This is a key detective and preventive control in governance frameworks. Least privilege limits access to the minimum needed; need to know restricts information access; mandatory access control uses classification labels.

Question 10 of 10
A company is moving its web application to the cloud and needs to ensure that the cloud provider encrypts data, manages patching of the operating system, and handles physical security, while the company manages the application code and user access. Which cloud service model is being described?
  • A. Infrastructure as a Service (IaaS)
  • B. Platform as a Service (PaaS)
  • C. Software as a Service (SaaS)
  • D. Function as a Service (FaaS)
Answer: B

In Platform as a Service (PaaS), the cloud provider manages the infrastructure, operating system, and runtime environment, including patching and physical security. The customer is responsible for the application code, data, and user access management. In IaaS, the customer manages the OS and everything above it. In SaaS, the provider manages nearly everything. Understanding the shared responsibility model for each cloud service model is essential for the Security+ exam and real-world cloud security.
